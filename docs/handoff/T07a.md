# T07a handoff: web static foundation

## What was done
Built the static frontend foundation (vanilla JS ES modules, no framework, no build step,
no external libraries/CDNs). All user-visible text is in Thai.

## Files
- `web/index.html` — HTML5 skeleton: `lang="th"`, viewport meta, title "Realm of Villages",
  links `css/style.css`. Contains `#topbar` (4 resource spans `res-wood/stone/iron/food`
  with emoji + value span, `#clock`, `#pause-btn`, `#village-select`), `#view`,
  `#bottomnav` (5 `.nav-link` links: #/ หมู่บ้าน, #/center ใจกลาง, #/map แผนท่ี,
  #/reports รายงาน, #/ranking อับดับ), `#toast` (hidden), and
  `<script type="module" src="js/app.js">` at end of body.
- `web/css/style.css` — mobile-first (360px+), CSS variables, system-ui + Noto Sans Thai.
  Fixed top bar / bottom nav, toast above nav with `.toast-error`, buttons
  (`.btn`, `.btn-primary`, `.btn-danger`, `:disabled`), `.panel`, `.negative`,
  resource colors (wood #8b5a2b, stone #8a8f98, iron #4a6fa5, food #6a994e),
  `.field-grid` (6×3 square cells), `.slot` (+ `.wood/.stone/.iron/.food/.empty/.building`
  with 🔨 corner badge), `.center-grid` (4 columns), `.bottom-sheet`, `.list-row`,
  `.countdown` (monospace).
- `web/js/api.js` — `ApiError` class (fields `code`, `message`, `status`);
  `api.get(path)`, `api.post(path, body)`, `api.patch(path, body)` where `path` is relative
  to `/api`. JSON in/out. Non-2xx → parses `{error:{code,message}}`, falls back to
  `HTTP_ERROR` / `เกิดข้อผิดพลาด (<status>)`; network failure → `NETWORK` /
  `เชื่อมต่อเซิร์ฟเวอร์ไม่ได้`. 204 → `null`.
- `web/js/clock.js` — `syncClock(gameNowIso)` sets `offsetMs = Date.parse(game_now) - Date.now()`;
  `gameNow()` → `new Date(Date.now() + offsetMs)`; `remainingMs(iso)` (min 0);
  `countdown(iso)` → `'H:MM:SS'` (hours not zero-padded, min `'0:00:00'`).
- `web/js/ws.js` — `onChanged(cb)` registers a callback (returns unsubscribe fn) called with
  the parsed message for every `{type:'changed', kind, village_id}`. Lazy connect to
  `ws(s)://<location.host>/ws`, auto-reconnect with backoff 1, 2, 5, 10, 10, ... s
  (reset after successful open), sends `'ping'` every 25 s while open, ignores `'pong'`
  and unparsable messages.
- `web/js/format.js` — `fmtNum(n)` (floor + comma thousands, keeps minus),
  `fmtDuration(seconds)` (ceil to whole seconds, `'H:MM:SS'`), `fmtTime(iso)`
  (`toLocaleString('th-TH')`, `''` for falsy/invalid).

## Public functions
- api.js: `class ApiError`, `api.get/post/patch`
- clock.js: `syncClock`, `gameNow`, `remainingMs`, `countdown`
- ws.js: `onChanged`
- format.js: `fmtNum`, `fmtDuration`, `fmtTime`

## Limits / notes
- `index.html` references `js/app.js`, which is created in a later task (T07b+);
  the page will 404 on that script until then (expected).
- `fmtNum` uses `toLocaleString('en-US')` for grouping so the separator is always a comma
  regardless of browser locale.
- ws.js keeps a single shared connection; unsubscribing the last callback does not close it.
- `countdown`/`remainingMs` clamp to 0 for past/invalid timestamps.
