# T04b — services: worlds (Phase 0)

## What was done
Implemented `realm/services/worlds.py` per BUILD.md 8.8, Phase 0 (T04): a new running
world with a single tile, one human player and its capital village. `end_round` is
intentionally NOT implemented (added by a later task).

## Files
- `realm/services/worlds.py` (new)
- `tests/services/test_worlds.py` (new, 10 tests, all passing)

## Public functions
- `current_world(s) -> World` — newest running world; `GameError(NOT_FOUND)` if none.
- `world_now(world, real_now) -> datetime` — delegates to `realm.core.clock.game_now`.
- `create_world(s, *, seed, speed, player_name, tribe, bot_count, cfg, real_now) -> World`
- `pause(s, real_now) -> World` — idempotent; sets `paused_at = real_now`.
- `resume(s, real_now) -> World` — no-op if not paused; else adds the paused span to
  `paused_total_s` and clears `paused_at`.

## Behavior / decisions
- Validates `tribe in cfg.tribes` and `speed in (1, 3, 5, 10)` → `INVALID_TARGET` (Thai message).
- Closes prior running worlds with `UPDATE worlds SET status='ended' WHERE status='running'`.
- `created_at` = `game_epoch` = `real_now`; player/village timestamps use `game_epoch`.
- Single tile at (0,0), kind `valley`, layout `4-4-4-6` (capital layout constant).
- Village name `f'หมู่บ้านของ{player_name}'`, resources from `cfg.world.start_resources`.
- Buildings from `realm.core.slots.initial_buildings(layout, cfg)` (18 fields L0,
  town_hall L1 slot 19, rally_point L0 slot 39, wall L0 slot 40) = 21 rows.
- Durations from cfg: `ends_at = epoch + round_days*86400/speed`,
  `protection_until = epoch + protection_hours*3600/speed` (timedelta seconds).
- Schedules `ROUND_END` via `realm.services.events.schedule` with payload `{}` at `ends_at`.
- Phase 0: `bot_count` is accepted but ignored (no bots, no bot profiles) — T10 replaces this.
- Flushes after inserts for id availability; never commits; never calls `datetime.now()`.
