# T33 — Phase 3: rate limit, duplicate-command guard and audit log (auth mode)

## What was done
Added a Starlette `BaseHTTPMiddleware` that, only when `settings.auth_required` is True,
guards mutating (`POST/PUT/PATCH/DELETE`) requests under `/api/`:

1. **Rate limit** — sliding-window counter per actor key. Over `settings.rate_limit_per_10s`
   requests in 10 s → `429` with `error.code = "RATE_LIMITED"`.
2. **Duplicate guard** — for non-`/api/auth/` paths, a `sha256(key|method|path|body)`
   fingerprint repeated within 1 s → `429` (`RATE_LIMITED`).
3. **Audit log** — after the response (and for 429s) `record_audit` is run in a threadpool,
   writing an `AuditLog` row (account/player resolved from the session token). Errors are
   swallowed so audit never breaks a request.

Actor key: `c:<sha256(cookie)[:16]>` when the `rov_session` cookie is present, else
`ip:<host>` (or `ip:unknown`). `/api/auth/*` paths always use the IP key (brute-force
protection) and skip the duplicate guard.

With `auth_required` False the middleware passes every request through untouched.

## Files
- `realm/api/guard.py` (new) — all logic.
- `realm/api/main.py` — one edit: import `GuardMiddleware` and `app.add_middleware(GuardMiddleware)` in `create_app`.
- `tests/api/test_guard.py` (new) — unit + middleware tests.

## Public functions / classes (realm/api/guard.py)
- `class RateLimiter(clock=time.monotonic)` — `.allow(key, limit, window_s) -> bool`
- `class DuplicateGuard(window_s=1.0, clock=time.monotonic)` — `.is_duplicate(fingerprint) -> bool`
- `record_audit(token, method, path, status) -> None`
- `class GuardMiddleware(BaseHTTPMiddleware)` — `.dispatch(request, call_next)`
- module singletons: `limiter`, `duplicates`

## Notes / limits
- `record_audit` uses `datetime.now(UTC)` (allowed in the API layer) and `session_scope()`.
- The request body is read via `request.body()`; Starlette's `_CachedRequest` re-feeds the
  body downstream (verified by the echo-route test).
- Tests monkeypatch `guard.record_audit`, `guard.limiter`, `guard.duplicates` and
  `settings` so no real DB is touched; the `s` fixture is only used for the auth tests.
