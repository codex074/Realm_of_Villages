# T26a — Endgame backend: ruins spawn, ruin capture, monument rules, monument victory

## What was done
Implemented the endgame backend for the "Realm of Villages" game:

- **Ruins spawn** — new `realm/services/ruins.py` with `spawn_ruins(...)`:
  picks up to `cfg.ruins.count` valley tiles (no village, unowned) in the ring
  `[min_center_distance, max_center_distance]` from (0,0), at least
  `min_village_gap` from every village, greedily spaced >= `min_gap` apart
  (deterministic via `random.Random(f"{world.seed}:ruins")`). Each becomes
  kind `ruin` with `layout/oasis_type/oasis_owner_village_id` cleared and
  `animals` set to the guardian counts. Emits one `info` report
  ("ซากโบราณปรากฏขึ้น") per player and a `ruins` notification. Idempotent
  (returns `[]` if the world is not running or a ruin already exists).
- **Scheduling** — `worlds.create_world` now schedules `EventType.RUINS_APPEAR`
  at `game_epoch + cfg.ruins.appear_day * 86400 / speed`; `engine/handlers.py`
  registers `handle_ruins_appear` in `HANDLERS`.
- **Ruin attacks/capture** — `oasis.oasis_send_problem` and
  `oasis.resolve_oasis_arrival` now also handle `ruin` tiles: no radius and no
  max-per-village limits for ruins; unowned ruins are defended by guardians
  (stats from `cfg.ruins.guardians`); a winning ATTACK captures
  (`oasis_owner_village_id` = attacker village, animals cleared), a RAID never
  captures; guardians do not respawn; the previous owner gets
  `villages.after_change` and a "ซากโบราณของคุณถูกยึด" report. Report titles
  ("โจมตีซากโบราณ" / "ปล้นซากโบราณ" / "ยึดซากโบราณสำเร็จ"), defender label
  "ผู้พิทักษ์", target name "ซากโบราณ", and the `ruin: {captured}` data key
  replace the oasis equivalents. `military._check_send` routes ruin tiles
  through the oasis send check (SCOUT at a ruin is still rejected).
- **Monument rules** — `villages.owns_ruin(...)`, `villages.ruin_missing(...)`;
  `build()` raises `REQUIREMENTS_NOT_MET` ("ต้องยึดซากโบราณก่อน") when a
  monument is built without owning a ruin; `get_slot_view` adds that message to
  the monument option/upgrade `missing` and sets `affordable=False`.
- **Victory** — `views.RankingRow` gains `monument: int = 0`;
  `ranking.get_ranking` computes each player's highest monument level and sorts
  by (monument desc, population desc, villages desc, id asc).
  `worlds.end_round(...)` gains `winner_player_id` and `reason` (report data
  gains `"reason"`). `villages.complete_build` calls `worlds.end_round(...,
  winner_player_id=..., reason="monument")` when a monument reaches
  `cfg.ruins.monument_win_level` (lazy import to avoid a cycle). `worlds.get_map`
  fills the `oasis` info dict for ruin tiles too.

## Public functions
- `ruins.spawn_ruins(s, world_id, now, cfg) -> list[tuple[int, int]]`
- `villages.owns_ruin(s, village_id) -> bool`
- `villages.ruin_missing(s, village, btype) -> list[str]`
- `worlds.end_round(s, world_id, now, cfg, winner_player_id=None, reason="round") -> None`

## Limits / notes
- Ruin capture reuses the oasis column `oasis_owner_village_id` (per contract);
  `conquest.conquer_village` already frees it, so no change was needed there.
- `respawn_oases` already selects only `kind == 'oasis'`, so guardians never
  respawn (verified by the raid/weak-attack tests).
- `RankingRow.monument` defaults to 0, so existing ranking tests are unaffected
  unless a monument exists.
