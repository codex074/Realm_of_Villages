# T15c: web reports, ranking, troop training panel, unread badge

## What was done
- **reports.js** (new): `render(el, ctx, params)` for `#/reports` (list) and `#/reports/:id`
  (detail). List shows one clickable `.list-row` per report (title bold + `.unread` when
  unread, plus `fmtTime(created_at)`), navigates to `#/reports/<id>`; 'ไม่มีรายงาน' when empty.
  Detail fetches the report, dispatches `window` `reports-read` once, shows a back button,
  heading + time, and renders by kind: `battle` (win/lose banner, attack/defense power,
  attacker table, one table per defender or 'ไม่มีผู้ป้องกัน', loot, wall change), `scout`
  (success/fail banner; on success resources, troops, wall level, buildings), `reinforce`
  (units line), `info` (killed units and/or winner + your_rank + top list). Unknown kinds
  just show the title.
- **ranking.js** (new): `render(el, ctx)` fetches `/ranking`, renders a table with columns
  อันดับ/ชื่อ/เผ่า/หมู่บ้าน/ประชากร; the row where `player_id == state.player.id` gets class `me`;
  bots get a small `bot` tag.
- **slotpanel.js** (edited, existing exports unchanged): `openSlotPanel` now, when the slot
  has a current building, fetches `/villages/{id}/train-options`, filters to the current
  building type, and appends a 'ฝึกทหาร' section (per unit: name, four cost rows reusing
  `costRows`, per-unit time, missing lines, a จำนวน number input, max text, and a primary
  'ฝึก' button disabled when missing or max_affordable is 0; click POSTs `/train`, toasts
  'เริ่มฝึกแล้ว', refreshes; ApiError toasts and re-enables). Also a 'คิวฝึกทหาร' list of
  `village.training` entries for the current building with a countdown, or 'ไม่มีคิวฝึก'.
  A failing train-options fetch is ignored silently.
- **app.js** (edited minimally): added `updateReportsBadge()` (called from `updateNav`,
  which runs on every state change and first load) that sets the 4th `.nav-link` text to
  'รายงาน' or 'รายงาน (<n>)' when `state.unread_reports > 0`. Added a `window`
  `reports-read` listener that refetches `/state`, syncs the clock, and calls `updateTopbar()`
  only (no view re-render).
- **style.css** (appended only): new `/* reports + ranking + training */` section with
  `.unread`, `.list-row.clickable`, `.table`, `tr.me`, `.tag`, `.banner` (+`.negative`).
