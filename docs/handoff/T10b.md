# T10b — services: create_world (full world, bots, spawns)

## What was done
Replaced the Phase 0 body of `create_world` in `realm/services/worlds.py` with the full
implementation per BUILD.md 8.8 + T10:

- Ends all running worlds (`status='ended'`), then inserts the new `World`.
- Generates the full tile map with `worldgen.generate_tiles(seed, cfg)` and bulk-inserts it
  with `s.execute(insert(Tile), rows)` (plain dict rows: world_id, x, y, kind, layout, oasis_type).
- Chooses bots with `rng = random.Random(seed)`: per bot a personality key (`rng.choices` over
  `cfg.personalities[*].share`, YAML order) and a difficulty key (`cfg.difficulty_shares`).
- `worldgen.pick_spawns(tiles, seed, [spawn_min_radius per bot], cfg)` -> (player_pos, bot_positions).
- Human `Player` at player_pos with a capital village named `บ่านของ{player_name}{player_name}`.
- Each bot: `Player(is_bot=True, tribe=rng.choice(sorted(cfg.tribes)),
  production_mult=cfg.bot_difficulties[difficulty].production_mult, name=<unique Thai name>)`,
  a capital village with the same name, and a `BotProfile` (personality, difficulty,
  `next_think_at = game_epoch + uniform(0, think_interval_min*60/speed)`, `memory={}`).
- Bot names come from `realm.core.names.BOT_NAMES`; when `bot_count` exceeds the list, names
  repeat with a ` 2`, ` 3` ... suffix so they stay unique within the world.
- Every village gets `cfg.world.start_resources`, `res_updated_at=game_epoch`, and its buildings
  from `slots.initial_buildings(layout, cfg)` (via `s.add_all`).
- All players get `protection_until = game_epoch + protection_hours*3600/speed`,
  `cp_updated_at`/`created_at = game_epoch`, and `capital_village_id`.
- Schedules `ROUND_END` at `world.ends_at` with payload `{}`.

`current_world`, `world_now`, `pause`, `resume` and the validation
(unknown tribe / speed not in (1,3,5,10) -> `GameError INVALID_TARGET`) are unchanged.

## Limits / notes
- Tiles are bulk-inserted as plain dicts; players/villages/buildings/profiles use `add`/`add_all`
  with a flush per player (village id needed for buildings) — no per-row SELECT queries.
- Village layout is taken from the tile at the spawn position (all spawns are valley tiles).
