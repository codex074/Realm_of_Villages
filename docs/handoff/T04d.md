# T04d handoff — villages views (get_village_view, get_slot_view)

## What was done
Implemented the two read-only view functions required by BUILD.md 8.4, appended to the
end of `realm/services/villages.py`. All pre-existing functions and constants are
unchanged; only new imports were added at the top.

## Files
- `realm/services/villages.py` — appended `_brief`, `get_village_view`, `get_slot_view`.
- `tests/services/test_village_views.py` — new test module (7 tests, all with
  hand-computed literals from the config YAML).
- `docs/handoff/T04d.md` — this file.

## Public functions
- `get_village_view(s, player_id, village_id, now, cfg) -> VillageView`
  - lock_village → FORBIDDEN if not owner (reuses FORBIDDEN_TH) → settle_village.
  - resources from settled columns via `Res.to_dict()`; rates/capacity from
    `compute_rates`; hidden from `economy.hideout_capacity` with the player's tribe.
  - buildings: exactly 40 `BuildingView` for slots 1..40; missing rows →
    type None / level 0 / name_th None.
  - build_queue ordered by finishes_at; queue_limit from town hall level.
  - troops_home (home==location==village, summed per unit); reinforcements_here
    grouped by home village (`troop_ids`, `from_village` brief JSON, `units`);
    troops_away grouped by location village (`location` brief JSON, `units`).
  - training ordered by id; movements: outgoing (direction 'out', hostile False,
    units shown) + incoming (direction 'in'; hostile = mission in
    attack/raid/scout; units None for other players' armies, shown for own
    villages); all ordered by arrive_at; status 'done' rows excluded.
- `get_slot_view(s, player_id, village_id, slot, now, cfg) -> SlotView`
  - slot outside 1..40 → GameError INVALID_SLOT; ownership check → FORBIDDEN.
  - upgrade: only for existing buildings below max level; cost/time/missing/
    affordable from `construction` + current stock.
  - options: only for empty slots; every building accepted by
    `slots.slot_accepts` for the layout, skipping center types already present as a
    building row or in the build queue; target level 1.

## Private helper
- `_brief(s, village, cfg) -> VillageBrief` — population computed over all building
  rows as (type, level) pairs.
