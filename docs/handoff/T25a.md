## Public functions (realm/services/market.py)
- `market_info(s, village_id, cfg) -> dict` — `{'level', 'capacity', 'fee', 'merchant_speed'}`;
  level 0 when no marketplace, capacity = level * `cfg.market.capacity_per_level`.
- `send_resources(s, player_id, from_village_id, to_village_id, resources, now, cfg) -> Movement`
  — locks both villages in ascending id order, owner check (FORBIDDEN), destination must
  exist / belong to the same player / differ from the sender (INVALID_TARGET), settles the
  sender, requires marketplace level >= 1 (REQUIREMENTS_NOT_MET), validates keys
  (wood/stone/iron/food), non-negative values, floors to integers, total > 0 and
  <= marketplace capacity (INVALID_UNITS), stock check (INSUFFICIENT_RESOURCES), deducts,
  creates a `trade` Movement with `loot` = integer amounts as floats,
  `arrive_at = now + max(1.0, dist / merchant_speed * 3600 / world.speed)` seconds,
  schedules `MOVEMENT_ARRIVE`, after_change on the sender, notifies the owner.
- `resolve_trade_arrival(s, m, now, cfg) -> None` — locks and settles the destination,
  adds `m.loot` to its stock clamped to `[0, capacity]` (from `villages.compute_rates`;
  overflow is lost), marks the movement `done`, writes an `info` report titled
  'ส่งทรัพยากรถึงแล้ว' with `{'from_village_id', 'to_village_id', 'loot', 'delivered'}`,
  after_change and notify.
- `exchange(s, player_id, village_id, give, take, amount, now, cfg) -> dict`
  — owner check, settle, marketplace level >= 1, give/take must be two distinct
  resources, `amount = floor(amount) >= 1`; `gained = floor(amount * (1 - npc_fee) + 1e-9)`;
  deducts `give`, adds `gained` to `take` capped by storage capacity;
  returns `{'gave', 'received' (after capping), 'fee'}`.

## Error codes / messages used
`FORBIDDEN`/`villages.FORBIDDEN_TH`, `NOT_FOUND`/`villages.VILLAGE_NOT_FOUND_TH` (via
`lock_village`), `REQUIREMENTS_NOT_MET` with `ต้องมี {name_th} เลเวล 1`,
`INVALID_TARGET` with 'ปลายทางไม่ถูกต้อง' / 'ชนิดทรัพยากรไม่ถูกต้อง',
`INVALID_UNITS` with 'จำนวนไม่ถูกต้อง' / 'ปริมาณเกินความจุของตลาด',
`INSUFFICIENT_RESOURCES`/`villages.INSUFFICIENT_RESOURCES_TH`.

## Limits / notes
- `market.py` does not import `military` at module level (cycle-free); the
  `military -> market` edge is one-way.
- Shipment capacity is per-shipment (level * `capacity_per_level` total units),
  not per resource.
- `resolve_trade_arrival` assumes the destination still exists and belongs to
  the sender's player (true for trade movements created by `send_resources`).
- `exchange` `received` reflects the amount actually added after the storage
  cap; the fee is `amount - gained` regardless of capping.
