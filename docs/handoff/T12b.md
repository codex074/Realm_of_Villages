## Public API
- `ArmyGroup` (dataclass): `tribe`, `units: Units`, `owner_ref: int | None = None`.
- `BattleInput` (dataclass): `mission` (Mission.ATTACK or Mission.RAID), `attacker`,
  `defenders: list[ArmyGroup]`, `defender_tribe`, `wall_level`, `catapult_target_level`.
- `BattleResult` (dataclass): `attacker_won`, `attack_power`, `defense_power`,
  `attacker_losses`, `defender_losses` (same order as defenders), `wall_level_after`,
  `catapult_target_level_after`, `loyalty_damage`.
- `resolve_battle(inp: BattleInput, cfg: GameConfig, rng: random.Random) -> BattleResult`
- `resolve_scout(attacker_scouts: int, defender_scouts: int, cfg: GameConfig) -> tuple[bool, int]`
- `plunder(stock: Res, hidden_per_resource: float, carry: float) -> Res`

## Implementation notes
- Pure module: no DB/clock; randomness only via the passed `random.Random`.
- All numbers come from `cfg` (no hard-coded game values).
- Loss dicts omit units with 0 deaths; deaths capped at the unit count.
- Wall/catapult damage and loyalty damage only on ATTACK + attacker win;
  catapult target stays `None` when not targeted.
- `plunder` uses the water-filling algorithm; returns a `Res` of integer-valued floats.

## Tests (all hand-computed literals)
1. 100 swordsmen vs empty village: D = 10.0, win, no losses.
2. 100 stonehold spearmen vs 50 light_cavalry: D = 5760.0, defender wins,
   ATTACK losses 38/50, RAID losses 27/36 (RAID < ATTACK both sides).

4. Rams: 30 survivors -> wall 5 to 0; 12 rams -> wall 5 to 4; RAID/loser never damages wall.
   Catapults: 9 survivors, target 3 -> 2; None stays None.
5. RAID never changes wall or loyalty.
6. Loyalty: 2 surviving chiefs, seed 7 -> sum of two `randint(20, 30)` draws (25 + 22 = 47);
   deterministic per seed; 0 when no chief / RAID / attacker loses.
7. `resolve_scout`: (10,0)->(True,0), (10,5)->(True,4), (10,10)->(False,10), (10,20)->(False,10),
   attacker<=0 -> ValueError.
8. `plunder`: 316/50/316/316, take-all, hidden>stock -> zeros, carry 0 -> zeros, 100/100/100/100.
9. Two defender groups (stonehold + ironwild reinforcement): D = 10760, both groups lose 15
   (same ratio), reinforcement uses its own tribe inf_defense_mult.
