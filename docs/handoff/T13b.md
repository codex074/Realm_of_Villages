# T13b — services: arrival resolution (battle, scout, reinforce), reports, MOVEMENT_ARRIVE handler

## What was done

### resolve_arrival dispatch
After the existing `return` branch: `attack`/`raid` -> `_resolve_battle_arrival`,
`scout` -> `_resolve_scout_arrival`, `reinforce` -> `_resolve_reinforce_arrival`,
`settle` -> `GameError(INVALID_UNITS, "ยังไม่เปิดใช้")` (Phase 2 placeholder, unchanged message).

### Battle (attack/raid)
Target missing (None or deleted) -> return movement, no battle. Otherwise lock both villages in
ascending-id order and settle both; build defender groups from `Troop` rows at the target grouped
by home village (each group's tribe = its home owner's tribe); attacker group = the movement's
units with the attacker's tribe. `rng = random.Random(f"{world.seed}:{movement.id}")`.
Wall level from the target's `wall` building (0 if none). Catapult target only for ATTACK with
catapults: use `catapult_target` when the target has that building at level>0, else a random
existing center building (sorted by type), else None. Apply attacker/defender losses, update the
wall building (never delete fixed-slot rows), update the catapult building (delete center rows at
level 0). Loot only when the attacker wins: `plunder(stock, hideout_capacity, carry)`, subtracted
from the target's stock. Survivors -> return movement with the loot. A `battle` report goes to the
attacker, the target owner and every reinforcement owner (distinct players), with the exact
BUILD.md 8.7 JSON shape; titles `f'{label} {target.name}'` (attacker) and
`f'ถูก{label}โดย {home.name}'` (others), label `โจมตี`/`ปล้น`. `loyalty` is null (Phase 2).

### Scout
`combat.resolve_scout` over the movement's scouts vs all defending scouts at the target. Success ->
a `scout` report to the attacker only (resources floored, troops, wall, buildings). Failure ->
attacker report "หน่วยสอดแนมถูกจับได้ทั้งหมด" plus a `scout` report to the target owner
"ตรวจพบการสอดแนมจาก {home.name}". Survivors return via a return movement.

### Reinforce
Upsert `Troop(home=from_village, location=target, unit) += count`; `reinforce` reports to the
sender ("ส่งทัพเสริมไปยัง {target.name}") and, when the owner differs, to the target owner
("ได้รับทัพเสริมจาก {home.name}").

Every branch marks the movement `done`, calls `after_change` on the touched villages and notifies.
