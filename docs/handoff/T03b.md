## Behavior notes
- `db_engine` skips DB tests (with a hint to run
  `docker compose -f docker-compose.test.yml up -d`) if the test DB is unreachable;
  otherwise it does `DROP SCHEMA public CASCADE` + `CREATE SCHEMA public` then
  `alembic upgrade head` against the test URL.
- `s` opens a connection, begins an outer transaction, and binds a
  `Session(bind=conn, join_transaction_mode="create_savepoint")`; after each test it
  closes the session, rolls back the outer transaction and closes the connection.
- `REALM_TEST_DATABASE_URL` overrides the test URL
  (default `postgresql+psycopg://realm_test:realm_test@localhost:5433/realm_test`).
