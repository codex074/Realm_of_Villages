# T07c — web: village view, center view, shared slot panel

## What was done
Implemented the village page (`#/`, `#/v/:id`), the center page (`#/center`,
`#/v/:id/center`) and the shared build-queue / slot bottom-sheet panel. All DOM is
built with `h()`/`clear()` from `dom.js` (no innerHTML). Views follow the VIEW
CONTRACT: `async function render(el, ctx, params)`; they never fetch the village
themselves (only the slot view and mutation endpoints), and rely on `ctx.refresh()`
to re-render from fresh `ctx.village`.

## Files
- `web/js/views/slotpanel.js`
- `web/js/views/village.js`
- `web/js/views/center.js`
- `web/css/style.css` (appended `/* village + center + slot panel */` section only)

## Public functions
- `slotpanel.js`
  - `queuePanel(ctx)` -> `.panel` with heading คิวก่อสร้าง, one `.list-row` per
    `build_queue` entry (`<name_th> -> เลเวล <target_level>` + countdown span), a
    muted ไม่มีก่อสร้าง row when empty, and `ช่องก่่อสร้าง: <n>/<queue_limit>`.
  - `openSlotPanel(el, ctx, slot)` -> removes any existing `.bottom-sheet` in `el`,
    fetches `GET /villages/{id}/slots/{slot}`, appends a `.bottom-sheet` with a
    ปิด close button, a title (current name_th + เลเวล N, or ช่องว่่าง #<slot>),
    an upgrade block (4 resource costs with `.negative` when short, `fmtDuration`
    time, `.negative` missing lines, primary อัปเกรดเป็นเลเวล <n+1> button disabled
    when not affordable), one block per empty-slot option (name_th, costs, time,
    missing, สร้าง button), and a กำลังก่่อสร้างอยู่ note with disabled buttons when
    the slot is in the build queue. Build/upgrade buttons disable, POST
    `/villages/{id}/build`, toast เริ่่มก่่อสร้างแล่ว, `await ctx.refresh()`; on
    ApiError toast + re-enable. Slot-fetch errors toast.
- `village.js`
  - `render(el, ctx)` -> heading (name + เปลี่่ยนชื่่อ prompt button ->
    `PATCH /villages/{id}` + refresh), ผลิต/ชม. rates row (food `.negative` when < 0),
    `.field-grid` of slots 1..18 (produces color class, `.slot-level`, `.slot-label`,
    `.building` when queued, click -> openSlotPanel), `queuePanel`, a
    ทหารในหมู่บ่าน panel (`<unit> x<count>` or ไม่มีทหาร), and a ทัพ panel
    (direction arrow →/←, mission label, `(x, y)`, units list when not null,
    countdown to arrive_at, `.negative` when hostile; ไม่มีทัพเคลื่่อนท่ี when empty).
- `center.js`
  - `render(el, ctx)` -> heading ใจกลางหมู่บ่าน, `queuePanel`, `.center-grid` of
    slots 19..40 (name_th or ว่าง/`.empty`, level when type present, `.building`
    when queued, click -> openSlotPanel). Troop training UI intentionally omitted.
