# T26b — bots: ruins race and monument building

## What was done
Added two endgame bot modules and wired them into the brain registry:

- `modules.monument(ctx)`: builds/upgrades the monument when the village owns a ruin,
  the palace is level 10+, `construction.missing_requirements('monument', ...)` is empty,
  and the monument level is below `cfg.ruins.monument_win_level`. Returns ONE `build`
  action (score 5.5, `btype='monument'`) on the existing monument slot or the first empty
  center slot. `[]` otherwise.
- `modules.ruins_race(ctx)`: when a ruin tile exists, the village has `rally_point` level >= 1
  and troops at home, it gathers the home army (all units that are not scout/settler/chief),
  computes its total attack, and evaluates each ruin tile NOT owned by this player's villages.
  Defence of an unowned ruin = `cfg.combat.base_village_defense` + sum over `tile.animals`
  of `count * max(guardian.def_inf, guardian.def_cav)`; an owned ruin = `base_village_defense`.
  A candidate qualifies when `attack >= 1.3 * defence`; the nearest qualifying tile
  (torus `movement.distance`, then (x, y)) is chosen. Returns ONE `attack` action (score 3.8).
  `[]` otherwise.

## Files
- `realm/bot/modules.py` — added `monument` and `ruins_race` (read-only, single ruin query).
- `realm/bot/brain.py` — added both modules to `_MODULES`; added weight keys
  `monument -> monument` (default 1.0 when missing) and `ruins_race -> ruins_race`
  (default 0.0 when missing); added `monument` to `_BUILD_WEIGHT_KEYS` so the
  build-queue-full skip covers it; extended the pre-`active_from_day` military damping
  (x0.3) to include `ruins_race`.
- `realm/config/bots.yaml` — warlord weights gained `ruins_race: 1.5` (per task spec).
- `BUILD.md` — section 5.5 warlord weights line updated with the same `ruins_race: 1.5`.
- `tests/bot/test_ruins_bot.py` — 17 tests covering the module behaviour and brain
  integration (hand-computed numbers, Real columns only).

## Public functions
- `realm.bot.modules.monument(ctx: BotContext) -> list[Action]`
- `realm.bot.modules.ruins_race(ctx: BotContext) -> list[Action]`

## Limits / notes
- The 1.3 attack/defence margin is a fixed heuristic constant (not a cfg key); the base
  defence (10) and guardian stats are read from `cfg`.
- `ruins_race` skips memory-based failure tracking (per spec).
- `monument`/`ruins_race` are read-only; they never mutate the DB.
