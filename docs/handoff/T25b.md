## Public functions (routes/market.py)
- `GET /villages/{village_id}/market` → `{level, capacity, fee, merchant_speed}`.
- `POST /villages/{village_id}/trade/send` (TradeBody) → `MovementView` (via `movement_view`).
- `POST /villages/{village_id}/trade/exchange` (ExchangeBody) → `{gave, received, fee}`.

Both POST routes are guarded by `require_running`; all three check village ownership
(NOT_FOUND when missing, FORBIDDEN when another player's).

## Limits / notes
- Ownership is checked by loading the Village directly (not `villages.lock_village`), per the task.
- The web send form has no per-input capacity hint; the server enforces the shipment
  capacity and returns INVALID_UNITS.
- A failing market fetch in the panel is swallowed (the rest of the sheet is unaffected).
